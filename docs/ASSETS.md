# 素材与复现边界

| 内容 | 默认候选版 | 完整本地预览 |
| --- | --- | --- |
| 角色、手势、油画背景、松饼、官方标志 | 按原尺寸生成中性几何占位 PNG | 从本人持有的原工程导入 |
| 《星降る海》录音 | 自动生成静音 WAV | 导入原音频，保持 169.1 秒源偏移、2.6 秒暂停等时间参数 |
| 歌词译文 | 示例字幕，保留时间与演出 | 导入原 HTML 字幕 |
| macOS Hiragino 等字体子集 | 不分发，改用系统字体回退 | 从原工程导入，仍需遵循各自许可 |
| Ma Shan Zheng 中文字体子集 | 附 OFL，可分发 | 与原版一致 |
| 用户提供的烟花 HTML | 不分发，改用独立演示 | 原版效果随私有原 HTML 还原 |
| 参考录屏、原作截图、聊天与批量 QA 图片 | 不分发 | 留在原档案 |
| 封面和导出 MP4 | 不分发 | 保留在原交付目录 |

`config/assets.json` 记录被排除图像的相对路径、尺寸、原文件 SHA-256；它不是素材授权证明。`config/private-runtime.json` 绑定最终 HTML 快照，阻止从不匹配版本导入。

`npm run setup` 只在文件缺失时生成占位资源，不覆盖已有文件。需要改成自己的作品时，使用自己的图像/音乐/字幕，并确认完整尺寸、源音频偏移和字幕布局；原占位图仅用于验证技术结构。
