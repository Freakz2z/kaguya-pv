`config/assets.json` 登记此次公开的 25 张图像的相对路径、来源、尺寸和原文件 SHA-256。素材不是按 MIT 授权，具体边界见 [图像声明](../assets/NOTICE.md)。`config/private-runtime.json` 绑定原版 HTML 快照，阻止从不匹配版本导入。

`npm run setup` 检查所有登记图像的摘要，并补齐本地静音音轨和 GSAP；不会下载、复制或上传原曲。修改图像后同步清单的尺寸和摘要，保留自己的修改再运行安装。`npm run audit:repo` 拒绝清单之外的画面素材、音视频文件和常见改名音视频载荷；PNG 也会检查文件结构与尾部。
